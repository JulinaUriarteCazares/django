2. Patrón Strategy

Capa de servicios

La estrategia se selecciona por nombre de categoría. Cada clase encapsula una forma distinta de calcular el descuento y permite cambiar la regla sin modificar el endpoint.

products/services.py
class EstrategiaDescuento:
    def calcular(self, precio):
        raise NotImplementedError

class DescuentoElectronica(EstrategiaDescuento):
    def calcular(self, precio):
        return precio * 0.90

class DescuentoRopa(EstrategiaDescuento):
    def calcular(self, precio):
        return precio * 0.80

class SinDescuento(EstrategiaDescuento):
    def calcular(self, precio):
        return precio

def obtener_estrategia(categoria_nombre):
    estrategias = {
        'Electronica': DescuentoElectronica(),
        'Ropa': DescuentoRopa(),
    }
    return estrategias.get(categoria_nombre, SinDescuento())
Estrategias probadas: Electronica = 10% de descuento; Ropa = 20% de descuento.

3. Factory Method

Creación con categoría por defecto

El método de clase centraliza la creación de un producto sin categoría explícita. Obtiene o crea la categoría Sin categoría y devuelve el objeto listo para usarse.

products/models.py
@classmethod
def crear_con_categoria_default(cls, name, description, price):
    categoria_default, _ = Category.objects.get_or_create(
        name='Sin categoría'
    )
    return cls.objects.create(
        name=name,
        description=description,
        price=price,
        category=categoria_default,
    )
Por qué es creacional: el método encapsula el proceso de instanciación de Product y garantiza una configuración inicial válida.

4. Facade

Endpoint protegido

El endpoint ofrece una única llamada sencilla al cliente y oculta la búsqueda del producto, la selección de estrategia y el cálculo del descuento.

products/views.py y products/urls.py
@api_view(['GET'])
@permission_classes([IsAuthenticated])
def precio_final(request, pk):
    producto = get_object_or_404(Product, pk=pk)
    categoria_nombre = producto.category.name if producto.category else None
    estrategia = obtener_estrategia(categoria_nombre)
    precio_con_descuento = estrategia.calcular(float(producto.price))
    return Response({
        'producto': producto.name,
        'precio_original': producto.price,
        'precio_final': round(precio_con_descuento, 2),
    })

path('products/<int:pk>/precio-final/', precio_final, name='precio-final')
